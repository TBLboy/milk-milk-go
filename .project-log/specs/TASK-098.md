# TASK-098 平板服务器 IP 四段均可编辑

## 1. 目标

允许操作员在 Android 登录页的系统设置弹窗中编辑服务器 IPv4 的四个网段。

- 前两段默认值为 `192`、`168`；
- 第三、第四段继续由操作员填写；
- 端口 `8011` 和路径 `/api/v1/` 保持系统固定；
- 保存时校验四段均为 `0-255` 的整数。

## 2. 范围

- 修改 `LoginScreen` 的服务器设置状态、输入框和保存逻辑；
- 将服务器 URL 解析从只支持固定 `192.168.x.x` 改为通用 IPv4；
- Android 版本提升为 `1.0.3`、`versionCode=4`；
- 重新构建并签名 APK。

不修改后端和 Windows 安装包。

## 3. 完成条件

- 登录页服务器设置显示四个独立输入框；
- 前两段默认显示 `192`、`168`，但可以编辑；
- 保存后生成完整的 `http://<四段IP>:8011/api/v1/`；
- 非法或缺少网段时阻止保存；
- Android Debug 构建、Lint 和发布 APK 构建通过；
- APK 版本为 `1.0.3 / versionCode=4`，签名和 SHA-256 校验通过。

## 4. 验证边界

- 使用 Android 15 模拟器检查设置弹窗和四段输入控件；
- 未在真实平板执行覆盖安装；该结果由用户现场安装验证。

权限级别：B。该修改只扩展地址输入能力，不改变接口、端口或数据协议。
