# TASK-097 构建 1.0.2 演示测试安装包

## 1. 目标

在现有功能冻结基线上生成一组可直接安装的测试产物：

- Windows 11 NSIS EXE 安装包；
- Android 发布签名 APK；
- 新安装数据库自动初始化演示辅料、产品配方和演示工单。

本任务用于客户/现场 Demo 测试，不等同于 `TASK-089` 的最终正式发布。

## 2. 版本与范围

- PC 后端、Windows 安装器版本统一为 `1.0.2`。
- Android `versionName=1.0.2`、`versionCode=3`。
- 使用现有固定发布证书签名。
- 不改变业务逻辑、接口或数据库结构。
- 不提交或推送 Git。

## 3. 演示初始化

安装器在全新数据库上执行 `seed_install.py`，写入：

- 辅料：精制白砂糖、维生素 D3 粉、西番莲风味香精、活性乳酸菌粉；
- 产品配方：高钙纯牛奶 1L、西番莲风味酸乳；
- 演示工单：`WO-20260909-001`。

已有数据库存在主数据时，初始化脚本不覆盖既有内容。

## 4. 产物

- `发布版本/牧衡辅料称重防错系统-Windows-1.0.2-Setup.exe`
- `发布版本/牧衡辅料称重防错系统-Android-1.0.2.apk`
- 对应 `.sha256` 校验文件

## 5. 验证矩阵

- 后端完整测试通过。
- PC TypeScript/Vite 生产构建通过。
- Windows NSIS 安装包构建成功并识别为 PE32 GUI 安装程序。
- APK 构建、v2/v3 签名校验通过，版本为 `1.0.2 / versionCode=3`。
- 临时数据库执行初始化后得到 4 种辅料、2 个产品和 1 张工单。
- 两个产物的 SHA-256 校验通过。
- `git diff --check` 通过。

## 6. 未验证边界

- 未在真实 Windows 11 执行安装、服务注册、防火墙和覆盖升级。
- 未在真实 Android 平板执行本轮 APK 覆盖安装。
- 用户现场安装测试仍是本任务之后的必要证据。
