# TASK-106 修正预览二维码误判与自动缩放抖动

## 1. 问题

1.0.5 扫码有明显改善，但用户反馈有时识别到正确二维码后提示“不是本系统标签”，同时镜头持续放大缩小。

代码核查确认，普通标签预览二维码只包含 `preview=true` 和 `materialId`，按既定业务规则不包含正式 `labelId`。它被扫码时会命中“二维码可解析但没有 labelId”的异常分支，但原提示无法说明用户扫到的是预览码。另一方面，ML Kit 的缩放建议会在连续帧中反复请求不同倍率，原实现没有节流和次数上限。

## 2. 修复目标

- 识别并单独提示“标签预览二维码”，明确要求先在电脑端点击“打印”；
- 对 JSON 二维码增加 BOM、外层引号和前后附加文本容错；
- 自动缩放请求进行量化、节流，并限制单次扫码会话最多四次；
- 预览码或非本系统码出现后停止继续缩放，避免镜头来回抖动；
- 不把预览二维码升级为正式标签，不改变正式 `labelId` 校验。

## 3. 验证边界

本地完成 Android Debug、Lint、签名 APK 构建和模拟器安装启动检查。真实平板上对普通预览、放大预览、正式标签和供应商二维码的提示准确性与缩放稳定性需要用户验收。
