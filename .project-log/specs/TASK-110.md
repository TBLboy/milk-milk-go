# TASK-110 修复已驳回账号无法重新注册

## 1. 背景

普通操作员提交注册申请后，如果管理员将其驳回，原用户名仍保留在 `users` 表中。当前注册接口对所有已存在用户名统一返回 `USERNAME_EXISTS`，导致申请人不改用户名时永久无法重新提交，而驳回记录本身也不支持重新编辑。

## 2. 业务规则

- 注册申请被驳回后，允许申请人使用同一用户名重新提交。
- 重新提交时更新姓名、密码和可选工号，并把原记录重新置为 `pending`。
- 原驳回审计日志保留，同时新增 `account.registration_resubmitted` 审计记录。
- 待审批或已启用账号仍禁止使用同一用户名重复注册。
- 工号唯一性继续全局校验，但允许重新提交者沿用原记录中的工号。
- 重新提交会增加 `auth_version`，防止旧会话继续有效。

## 3. 实施范围

- 修改 `POST /auth/register` 对 `rejected` 用户记录的处理。
- 增加驳回后重新注册、重新审批、新密码登录的回归测试。

## 4. 验收条件

- 被驳回用户使用同一用户名可再次提交并重新进入审批中心。
- 重新提交后姓名、密码、工号和状态正确更新。
- 原驳回申请人和账号 ID 保持可追溯。
- 待审批或已批准账号重复注册仍返回 `USERNAME_EXISTS`。
- 后端专项与完整回归测试通过。

## 5. 限制

本次只解决注册申请驳回后的重新提交，不改变管理员审批和驳回规则。
