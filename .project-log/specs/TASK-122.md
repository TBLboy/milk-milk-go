# TASK-122 适配工作台、工单列表与工单详情

## 1. 任务目标与非目标

在 TASK-121 建立的 `COMPACT/EXPANDED` 布局基线上，适配 APP 工作台、工单列表和工单详情，使手机横屏下信息不被横向截断、分页和步骤操作可达；平板继续保持适合宽屏的多列布局。

本任务不修改后端接口、数据模型、工单状态机、权限规则、扫码/称重弹窗内部布局，也不调整 Android 版本号。

## 2. 业务原子与验收

- `BL-DEVICE-003`：APP 固定横屏，手机和平板功能与权限完全一致，按可用宽高自适应。
- `AC-DEVICE-003`：手机横屏所有页面、菜单、按钮和弹窗可到达且无不可恢复的遮挡。
- `AC-DEVICE-004`：同一账号在手机和平板上功能、权限和业务结果一致。
- `DEC-045`：单一横屏 APP，不提供手机精简版或平板独占功能。

## 3. 现有行为

- 工作台使用固定 `30dp` 外边距、固定 `220dp` 统计卡和固定 `264dp` 最近工单视口。
- 工单列表使用固定 `30dp` 内容间距，筛选按钮单行排列且没有横向滚动。
- 工单行和详情步骤卡使用固定图标、内边距和文本尺寸，长内容主要依赖换行。
- 工单详情外层已支持纵向滚动和下拉刷新，步骤操作与申请按钮已存在。

## 4. 目标行为

- 工作台在手机紧凑模式下使用较小外边距、标题字号和最近工单视口高度。
- 统计卡在紧凑模式下按可用宽度等分，避免展开侧边栏后横向溢出。
- 工单列表筛选栏在窄宽度下可横向滚动；列表和分页保持可达。
- 工单行在紧凑模式下压缩图标、内边距和字号，长产品名使用单行省略。
- 工单详情在紧凑模式下使用较小外边距和标题字号；步骤卡保持按钮可达并允许长文本合理换行或省略。
- 平板端仍使用原有宽屏间距、统计卡宽度和最近工单视口。
