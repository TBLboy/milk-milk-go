# TASK-094 Demo 标签生成界面与真实打印语义对齐

## 1. 背景

`DEC-037` 已确认当前 Demo 不接入真实标签打印机，只保留标签生成、二维码预览、标签记录和打印批次记录。真实打印机连接、打印状态、重打、作废和贴标复核由后续 `TASK-086` 实施。

当前 PC 仍显示“生成并打印标签”“打印完成后请粘贴”等完成打印语义，`BL-LABEL-002` 也仍要求当前阶段向打印机发送指令。这会让演示人员误判系统已经完成物理打印。

## 2. 范围

- 将 PC 标签模块在当前 Demo 中统一表达为“标签生成与预览”。
- 保留“标签打印”作为后续正式能力，不在本任务删除后端 `PrintBatch`、`Label` 或 `printedAt` 数据模型。
- 修正页面标题、操作按钮、数量字段、提示语、批次表和导航入口。
- 更新 `BL-LABEL-002` 为当前 Demo 行为，并引用 `DEC-037`。
- 保留现有生成批次、唯一 `labelId`、`printedAt` 和二维码预览接口行为。

## 3. 界面要求

- 页面标题使用“标签生成”。
- 页面说明明确当前只生成标签记录和二维码预览，不发送真实打印任务。
- 主按钮使用“生成标签记录”。
- 数量字段使用“生成张数”。
- 批次列表使用“最近生成批次”“生成批次”“生成人”和“生成时间”。
- `pending` 批次状态在当前 Demo 显示为“已生成”，不得显示为“待打印”或“已打印”。
- 导航和仪表盘入口使用“标签生成”。

## 4. 业务原子

`BL-LABEL-002` 调整为：

```text
当前 Demo：
选择辅料和数量
→ 系统生成对应数量 labelId
→ 记录服务端 printedAt
→ 返回二维码预览和批次记录
→ 不发送打印指令
```

真实打印机连接、指令发送、打印状态、重打和作废仍由 `TASK-086` 负责。

## 5. 验证

1. PC TypeScript/Vite 生产构建通过。
2. 浏览器验证页面不存在“生成并打印标签”和“打印完成后粘贴”。
3. 浏览器验证“生成标签记录”仍提交真实生成请求、返回批次并保持二维码预览。
4. 后端标签专项测试和完整回归通过。
5. `git diff --check`、Project Log 和 Loop 校验通过。

## 6. 完成边界

本任务只修正当前 Demo 的语义和文档，不实现任何打印机驱动、打印指令、状态回传或物理输出。
