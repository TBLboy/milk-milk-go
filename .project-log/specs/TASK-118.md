# TASK-118 电脑端动态下拉框支持输入搜索

## 1. 背景

电脑端标签打印、新建工单、配方编辑和审计筛选使用原生下拉框。辅料、产品、操作员等数据量增加后，逐项滚动选择效率低，也容易选错。

## 2. 业务规则

- 动态数据下拉框既支持展开列表选择，也支持直接输入关键字筛选。
- 搜索范围包含显示名称、内部代号、账号或员工工号等可识别字段。
- 鼠标点击选项后回填选中值。
- 键盘上下键可以移动候选，回车可以确认当前候选，Escape 可以关闭。
- 搜索不会修改业务值；只有选中候选项才更新表单或筛选条件。
- 下拉菜单不能被弹窗滚动区域裁切。

## 3. 实施范围

- 新增电脑端复用的可搜索下拉组件。
- 标签打印的辅料选择。
- 新建工单的产品选择和操作员选择。
- 配方编辑中的辅料选择。
- 审计日志的操作人员、操作类型和结果筛选。
- 更新电脑端样式和生产构建产物。

## 4. 验收条件

- 标签打印可以输入辅料名称或代号并选中正确辅料。
- 新建工单可以输入产品名称和操作员姓名或账号并完成选择。
- 配方编辑可以输入辅料名称或代号并完成选择。
- 审计筛选项支持输入搜索且能正确写入筛选状态。
- 选择后下拉菜单关闭，输入框回填完整标签。
- TypeScript 和生产构建通过。
- 浏览器实际交互验证通过且控制台无错误。

## 5. 验证结果

- TypeScript 与 Vite 生产构建通过。
- Chrome + Playwright 验证：标签打印输入“白砂”可筛选并选中“白砂糖 · SUGAR-01”。
- Chrome + Playwright 验证：新建工单输入“高钙”和“李”可筛选并选中产品与操作员。
- Chrome + Playwright 验证：配方编辑输入 `FLAV` 可筛选并选中“西番莲香精 (FLAV-02)”。
- 选择后菜单关闭、输入框回填完整值，控制台无错误。
- `pc/src` 中已无原生 `<select>`，共 7 个可搜索下拉调用点。
- 证据：`EV-TASK-118-PC-BUILD`、`EV-TASK-118-BROWSER`、`EV-TASK-118-STATIC`、`EV-TASK-118-DIFF`。

## 6. 限制

- 当前验证覆盖 Chrome；正式交付前需确认客户使用的浏览器版本。
