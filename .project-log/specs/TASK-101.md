# TASK-101 APP 工单详情下拉刷新

## 1. 目标

在 Android App 的工单详情页增加下拉刷新，让操作员无需返回工单列表即可重新获取当前工单及步骤状态。

## 2. 范围

- 复用 `MainShell` 已有的 `isRefreshing` 状态和 `refreshDataWithFeedback()` 回调；
- 使用 Material 3 `PullToRefreshBox` 包裹工单详情页的纵向滚动内容；
- 刷新成功后，通过既有 `orders` 状态自动更新当前打开的工单详情；
- 不修改后端接口、列表分页、工单状态规则或审批/拍照对话框。

## 3. 完成条件

- 工单详情页在内容顶部继续下拉时触发全局刷新；
- 刷新过程中显示系统下拉刷新指示器；
- 刷新失败时沿用现有网络错误提示；
- Android Debug 构建与 Lint 通过。

## 4. 验证边界

- 自动化验证覆盖 Kotlin 编译和 Android Lint；
- 真机下拉手势与弱网反馈由后续现场验证补充。

权限级别：B。该修改只复用既有刷新链路并扩展一个页面入口，不改变业务语义或数据协议。
