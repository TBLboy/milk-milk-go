# TASK-100 增加标签尺寸设置并控制预览与后续打印

## 1. 目标

在 PC 系统设置中增加一个全局标签尺寸参数，控制标签预览的宽高比例，
并为后续真实打印机提供统一尺寸来源。

## 2. 参数规则

- 设置键：`label_size_mm`
- 默认值：`60x40`
- 输入格式：`宽x高`，单位毫米
- 允许范围：宽、高分别为 `10-300` 毫米
- 接受 `x`、`X` 或 `×` 作为分隔符，保存时统一为小写 `x`

示例：

```text
60x40
50 × 30
70X50
```

## 3. 范围

- 设置初始化、服务端校验和审计沿用现有 `system_settings` 接口。
- PC 系统设置页增加“标签尺寸”配置项。
- 标签页预览按设置后的宽高比例变化。
- 生成标签时把尺寸快照写入 `label_payloads[].labelSize`。
- 标签批次响应返回本次使用的 `label_size`。
- PC/后端版本提升到 `1.0.4` 并重建 Windows 安装包。

不修改二维码身份字段、扫码匹配规则或 Android 端业务行为。

## 4. 完成条件

- 新数据库自动初始化 `label_size_mm=60x40`。
- 非法尺寸返回 `LABEL_SIZE_INVALID`，合法尺寸格式统一。
- 修改设置后新生成标签携带对应尺寸快照。
- PC 标签预览随尺寸参数变化。
- 专项测试、完整后端回归、PC 构建和 Windows 安装包构建通过。

## 5. 验证边界

- 当前没有真实标签打印机，因此只验证参数、预览和标签 payload。
- 实际打印机纸张尺寸适配由后续打印机接入任务验证。

权限级别：B。该功能增加可逆的全局配置并复用已有标签语义。
