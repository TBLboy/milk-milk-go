# TASK-112 限制电脑端工作台最新工单为 5 条

## 1. 背景

电脑端工作台“最新工单”直接展示全部未撤销、未删除且符合筛选条件的工单。工单数量增加后，表格会持续变长，挤压工作台其他区域。

## 2. 业务规则

- 工作台“最新工单”区域最多展示 5 条。
- 搜索和状态筛选仍然生效，只在筛选结果中取最前面的 5 条。
- 完整工单列表继续通过“查看全部”进入工单管理页查看。

## 3. 实施范围

- 在 `Dashboard.tsx` 对筛选后的工单结果执行 `slice(0, 5)`。

## 4. 验收条件

- 后端返回 8 个工单时，工作台表格仅渲染 5 行。
- 搜索或状态筛选没有结果时仍显示空状态。
- PC 生产构建和差异检查通过。

## 5. 验证结果

- `npm run build` 通过。
- Playwright 注入 8 个模拟工单，工作台实际行数为 5。
- `git diff --check` 通过。
