# TASK-103 标签选择即预览并调整打印入口

## 1. 目标

简化 PC 标签页操作：选择辅料后立即显示该辅料的标签预览；原“生成标签记录”按钮改为“打印”。当前 Demo 不发送真实打印任务，但点击“打印”时仍生成正式标签记录和真实 `labelId`。

## 2. 业务规则

- 切换辅料只生成界面预览，不写入标签记录；
- 标签预览二维码标记为 `preview`，不得被视为可正式使用的标签；
- 点击“打印”时才按打印张数生成正式标签记录；
- 当前未接入物理打印机时，点击“打印”只生成记录并明确提示未发送打印任务；
- 正式标签仍使用独立 `labelId`、`materialId`、`printedAt` 和 `labelSize` 快照。

## 3. 范围

- 修改 PC `LabelsPage` 的选择、预览和按钮交互；
- 同步页面文案，避免把预览二维码描述成正式标签；
- 更新 `BL-LABEL-002` 和新增 `DEC-043`；
- 不修改后端标签接口和数据库结构。

## 4. 完成条件

- 页面加载或切换辅料后，右侧立即显示预览标签；
- 未点击“打印”时不新增数据库标签记录；
- 点击“打印”后按数量生成正式标签记录并刷新批次列表；
- 页面明确提示当前版本未发送真实打印任务；
- PC 生产构建通过。

## 5. 验证边界

- 不连接物理打印机；
- 不向生产数据库额外写入测试标签。通过前端构建和浏览器预览验证界面交互。

权限级别：B。该修改调整已确认的操作顺序，但不改变标签身份、记录结构或后端接口。
