# TASK-109 注册页密码自动填充与可选工号

## 1. 背景

平板注册页面会沿用登录页保存的密码状态，且系统自动填充可能把已有凭据带入注册密码框。注册申请目前也只允许管理员在审批前补充工号，注册人无法主动填写。

## 2. 实施范围

- 登录密码与注册密码使用独立状态，进入注册模式时清空注册密码和确认密码。
- 注册模式排除 Android 自动填充，登录模式继续保留应用自己的“记住密码”能力。
- 注册页新增可选工号输入框，并提交 `employee_no` 到后端。
- 后端注册接口接受可选工号，统一去除首尾空格，并校验工号唯一性。
- 工号留空时仍可提交注册，但管理员审批前必须补齐；注册时填写后可直接进入审批。
- 增加注册无工号、注册带工号、重复工号后端测试。

## 3. 验收条件

- 从登录页进入注册页时，密码框为空，不会自动带入已保存密码。
- 登录页“记住密码”和账号回填不受影响。
- 注册人可以选填工号；留空可提交，填写时后端保存并检查唯一性。
- 后端认证测试、Android Kotlin 编译和差异检查通过。

## 4. 限制

Android 系统输入法或密码管理器的具体弹窗行为仍需在真实平板安装最新 APK 后回归验证。
