# TASK-093 辅料主数据 Excel 导出

## 1. 背景

需求基线要求产品、配方和辅料主数据支持 Excel 模板导入/导出。当前产品与配方已支持导出，辅料管理只有模板下载和导入，缺少把现有辅料导出为同一模板结构的能力。

本任务补齐这一已确认缺口，使管理员可以导出全部辅料用于核对、备份和批量再编辑。

## 2. 范围

- 新增管理员专用辅料 Excel 导出接口。
- 导出工作簿第一行字段必须与现有辅料导入模板一致：
  - `material_code`
  - `name_zh`
  - `name_en`
  - `shelf_life_months`
- 每行导出一个辅料，按内部代号排序。
- PC 辅料管理页增加“导出辅料”按钮并调用真实接口。
- 不修改辅料表结构，不导出图片，不改变现有导入规则。

## 3. 接口

### `GET /api/v1/labels/excel-export`

- 仅管理员可访问。
- 返回 `.xlsx` 文件。
- 下载文件名：`materials-export.xlsx`。
- 文件表头与现有辅料导入模板一致。
- 辅料为空时仍返回带表头的有效工作簿。
- 不返回数据库主键、图片路径或审计字段。

## 4. 前端

- 在现有“下载模板”右侧显示“导出辅料”。
- 产品与配方页面继续显示“导出配方”。
- 下载失败时沿用现有导入/导出提示区域显示原因。
- 下载成功不弹出额外模态框。

## 5. 验证

1. 后端测试校验工作簿表头、全部辅料字段和内部代号排序。
2. 后端测试校验空辅料库能导出有效工作簿。
3. 后端测试校验普通操作员不能访问导出接口。
4. PC TypeScript 生产构建通过。
5. 浏览器验证点击“导出辅料”触发下载且文件名正确。
6. 后端完整回归、`git diff --check`、Project Log 和 Loop 校验通过。

## 6. 完成边界

本任务只补齐辅料主数据导出，不实现 Excel 增量合并、覆盖导入或图片打包导出。
