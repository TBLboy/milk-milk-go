# TASK-107 将当前 Demo 主数据写入 Windows 安装包并重建发布文件

## 1. 目标

把当前数据库中的 14 种演示辅料、6 个产品配方和可可粉包装图片固化为 Windows 安装器的种子数据，在全新安装和覆盖升级时幂等同步，不删除其他业务数据；同时重建 Windows `1.0.5` 和 Android `1.0.6` 发布文件。

## 2. 实施范围

- 替换旧版 4 种辅料、2 个配方的 `pc/server/seed.py`
- 在安装 payload 中复制 10 张可可粉包装图，并在首次安装/升级时写入 `%ProgramData%\MilkWeigh\data\uploads`
- 将 Windows/后端版本提升到 `1.0.5`
- 增加种子数据和 Windows 安装资源配置的自动测试
- 重建 Windows EXE 和 Android APK，更新发布校验文件

## 3. 验收条件

- 安装器种子数据包含 14 种辅料、6 个配方、29 条配方项和 10 张辅料图片。
- 种子脚本重复执行不产生重复主数据。
- 安装 payload 包含演示图片资源。
- Windows `1.0.5` 安装器成功编译并通过 SHA-256 校验。
- Android `1.0.6` APK 成功重建，版本为 `versionCode=7`，v2/v3 签名通过。
- 后端完整测试和 PC 生产构建通过。

## 4. 限制

真实 Windows 11 全新安装、覆盖升级、服务启动、防火墙和公司局域网内完整工单仍需现场验收。
