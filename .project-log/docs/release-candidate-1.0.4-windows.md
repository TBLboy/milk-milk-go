# Windows 1.0.4 测试安装包

## 新增功能

- PC 系统设置新增“标签尺寸”，格式为 `宽x高`，单位为毫米。
- 默认尺寸为 `60x40`，宽高允许范围为 `10-300` 毫米。
- 标签预览按配置的宽高比例显示。
- 生成标签时把本次尺寸快照写入标签 payload，后续打印机接入可复用。
