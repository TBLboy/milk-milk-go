# APP 登录页背景图生成简报

## Goal And Exact Question

生成一张适合 Android 平板 App 登录页使用的背景装饰图。图片用于平铺/铺满整个登录页底层，作为视觉装饰，不影响右侧登录卡片和左侧标题文字的阅读。

需要你生成：一张横向平板比例、现代、干净、偏浅色的牛奶生产/辅料称重主题背景图。

## Relevant Project Background

该 App 是“牧衡辅料称重防错系统”的 Android 平板端，用于牛奶生产企业现场称量辅料。

现场背景：

- 牛奶厂按产品配方生产不同奶制品；
- 操作员需要根据工单按顺序称取辅料；
- 系统要防止“辅料类型拿错、重量称错”；
- 辅料常见包装包括塑料桶、纸箱、蛇皮袋；
- 现场会使用平板扫码或拍照确认辅料，并在电子秤上称重；
- 系统是独立局域网系统，不依赖互联网。

## Current Layout

登录页是左右布局：

- 左侧：大面积留白，显示产品名“牧衡 / 辅料称重防错系统”和一句短文案；
- 右侧：约 420dp 宽的白色登录卡片，包含账号输入框、密码输入框和登录按钮；
- 当前底色：浅灰白 `#F5F7F9`；
- 主色：绿色 `#1F9469`；
- 文字色：深色 `#17202B`，次要文字灰 `#77858F`。

背景图放置后，右侧登录卡片仍需要保持清晰不遮挡。

## Image Requirements

- 比例：横向平板，建议 16:10 或 3:2，可裁切；
- 风格：现代、简洁、偏工业但不要太暗或太复杂；
- 主题：牛奶生产、奶制品、辅料原料、电子秤称重、标签/二维码、仓库/车间干净环境；
- 色彩：浅色为主，可以和绿色主色协调；
- 留白：左侧最好有较多干净空间，方便放置标题和文案；
- 右侧登录卡片区域不要放高对比度信息；
- 不要生成文字、水印、Logo；
- 不要生成夸张的营销元素、卡通人物、买牛奶广告。

## Constraints

- 只做背景装饰，不作为信息图表；
- 不能影响右侧白色登录卡片可读性；
- 需要适合平板横屏；
- 需要保持专业、克制、可信的工厂工具风格。

## Sample Prompt Mindset

“为一家牛奶生产企业的辅料称重防错系统生成一张平板登录页背景图。画面以奶制品生产、配料原料、电子秤称量、干净车间、标签追溯为主题，浅色、现代、简洁、低对比度。图片左侧保留大量干净空白作为标题区域，右侧区域不能有复杂内容。主色调与绿色 #1F9469 协调，不要出现文字、Logo 或广告元素。”

## Unknowns

- 最终是否接受插画风、真实摄影风格、还是极简抽象素材，需要用户视觉验收；
- 是否要保留半透明遮罩，以便登录卡片更突出；
- 最终图源和授权方式需要用户确认后使用。
